# Md Golam Muid Talukder - Full Stack Developer Portfolio

A modern, high-performance portfolio website built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**, designed specifically for **Md Golam Muid Talukder (Golam Muid)**.

## ✨ Features

- **Modern Dark Developer Aesthetic**: Sleek slate & zinc dark theme with ambient glowing gradients and glassmorphism.
- **Hero & Interactive Code Preview**: Live code card previewing profile, stack, and active availability.
- **Interactive Terminal / CLI Mode**: Press <kbd>T</kbd> or click the CLI button to launch an interactive terminal with custom commands (`skills`, `projects`, `experience`, `education`, `contact`, `cat resume`, etc.).
- **Career Timeline**: Detailed progression from Junior Frontend Developer to Full Stack Developer & Team Lead at ATI Limited.
- **Projects Showcase**: Deep-dive modals, live links, and GitHub repository links for production applications.
- **Skills & Tech Stack**: Interactive technology stack breakdown across Frontend, Backend, Databases, and DevOps with live search.
- **Academics & Credentials**: Ulster University (MSc in CS, Belfast, UK) and BRAC University (BSc in CSE).
- **Direct Resume Access**: Download and preview `Md-Golam-Muid-Talukder-Resume.pdf` with a single click.
- **Interactive Contact Form & Direct Actions**: One-click copy for email and phone, verified contact details, and simulated message dispatch.

## 🚀 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Static Generation)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animation & Transitions**: CSS transitions & Framer Motion ready
